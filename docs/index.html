How the 2-of-2 Programmable MPC Vault Works:
Standard Ethereum wallets rely on a single private key: if leaked or phished, your assets are compromised. scafonix Vault replaces this single point of failure with a 2-of-2 Multi-Party Computation (MPC) key:
  • Share A (Client / You): Stored locally in your browser or MetaMask Snap. Never leaves your hardware.
  • Share B (Policy Inspector): Held by an automated co-signer (vault-api.scafonix.com). Only signs if transactions strictly comply with your AWS IAM-style JSON security policy.
  • Share C (Emergency Recovery Voucher): Encrypted with your password. If the inspector ever shuts down, you can recover 100% of your funds locally without anyone's permission.

AWS IAM Policy Syntax Specification & Guide (Click to collapse)

scafonix Vault policies follow an AWS IAM-style JSON specification. During signature requests, the automated Inspector evaluates every statement against the proposed transaction parameters.

1. Evaluation Rules (Allow vs. Deny):
  • Default Deny: By default, all transactions are denied. A transaction is only approved if at least one statement with "Effect": "Allow" matches.
  • Explicit Deny Precedence: If any statement with "Effect": "Deny" matches the transaction, the transaction is immediately denied, regardless of any matching Allow statements.
